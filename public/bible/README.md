# 성경 본문 데이터 — 개역한글판 (1961)

- **판본**: 개역한글판(1961, 대한성서공회). 저작권 존속 기간이 지나 **퍼블릭 도메인**이므로
  공개 레포에 넣을 수 있다. 저작권이 살아 있는 **개역개정(1998)은 넣지 않는다** —
  개역한글은 "가라사대", 개역개정은 "이르시되"를 쓰고, `scripts/bible_check.mjs`가
  창세기 1:3으로 그 둘을 가른다.
- **출처**: [laisiangtho/bible](https://github.com/laisiangtho/bible) (MIT)의
  `json/88.json` — 커밋 `335be68`. 88은 개역한글의 bible.com 판본 번호다.
  받아서 한 번 변환해 넣었고, 변환기는 일회성이라 커밋하지 않았다:
  1~66번 책을 정경 순서로 돌며 유니코드 NFC 정규화 → 연속 공백을 하나로 → 양끝 자르기,
  그리고 장·절 번호가 1부터 빠짐없이 이어지는지 확인한 뒤 책마다 파일 하나로 썼다.
- **대조**: [seven1m/open-bibles](https://github.com/seven1m/open-bibles)의
  `kor-korean.osis.xml`과 절 단위로 맞춰 봤다. 겹치는 3만여 절에서 옛 표기(찌/지)와
  띄어쓰기를 접고 **93%가 글자까지 같았고**, 남은 차이는 그쪽 판의 오기(무엇로, 수보임,
  하살마웹)였다. 그쪽은 역대하 16장·욥기 1장·베드로전서 1장이 통째로 빠져 있어(1,189장 중 1,171장)
  대조용으로만 썼다.
- **모양**: `index.json`은 66권 목록(`id`·`name`·`abbr`·`chapters`), `<id>.json`은 책 하나
  (`chapters`는 장 배열, 각 장은 절 문자열 배열, **절 번호 = 인덱스+1**).
  66권 · 1,189장 · 31,103절.
- **남겨 둔 표기**: `(셀라)`, `[ ]`(사본에 따라 없는 대목), `(없음)`(마 17:21처럼 이 판에서
  비운 절), `(N절에 포함되어 있음)`(합쳐진 절)은 대한성서공회의 편집 표기라 그대로 뒀다.
  지우면 그 뒤 절 번호가 통째로 밀린다.

검사: `node scripts/bible_check.mjs`
