## 이 회차를 위해 준비해 둔 것

- `scripts/ui-shots.mjs` — 화면 네 조합 촬영. 실데이터는 운영을 **읽기만** 한다(쓰기 요청은 브라우저에서 가짜 성공 · 실시간 소켓 막음 · 마스터 임시 세션은 끝나면 회수).
  `--only home,club` · `--sizes phone` · `--themes dark` · `--path "?p=<id>" --name x` · `--click "선택자"`(창·시트를 열어 찍기) · `--guest`.
  모임 '동아리' 탭처럼 주소로 못 여는 탭은 화면 목록 셋째 칸(누를 버튼 글자)으로 연다. 보드는 업무가 가장 많은 살아 있는 프로젝트.
- shots/는 git 밖이다. 실데이터 사진에는 실제 얼굴·이름이 있으니 아티팩트에 올릴 때는 사용자에게만(비공개 기본) · 다 쓰면 지운다.
