## 7. 시안 만드는 방법(이 회차에 쓴 것)

- `mock/b1` 워크트리를 따로 만들어(`git worktree add <scratch>/mockwt mock/b1`) 에이전트 커밋을 cherry-pick → `npx vite build --mode guest` → `npx vite preview` + 헤드리스 크롬으로 처음 여는 브라우저 점검(콘솔 오류 0 · 가로 넘침 0) → push → Vercel이 미리보기를 만든다.
- 에이전트마다 포트를 나눈다(dev 48x1 · 크롬 96xx). 다른 세션 포트(4801 · 4598 · 9611~9619)는 쓰지 않는다.
- 게스트에는 로그인 세션이 없어 '멤버 관리'가 숨는다 — 시안에서는 게스트 시연일 때만 보이게 해 두었다(`layout.jsx`). 실제 앱 조건은 그대로.
